# 한 줄 다이어리

오늘 날짜가 자동으로 보이고, 한 줄만 적어 저장하는 브라우저 다이어리입니다.

- 같은 날 여러 번 적을 수 있고, 저장한 시각이 같이 남습니다.
- 기록은 최신순으로 보이며, 5개가 넘으면 목록 안에서 스크롤됩니다.
- 목록의 [수정]으로 기록을 바로 고칠 수 있습니다(Enter 저장, Esc 취소). 처음 쓴 시각은 그대로 남고, 고친 기록에는 `(수정됨)`이 붙습니다.

## 실행

`index.html`을 더블클릭해 브라우저로 엽니다. 빌드나 설치는 필요 없습니다.

브라우저 설정 때문에 파일로 열었을 때 저장이 안 되면, 이 폴더에서 로컬 서버로 엽니다.

```
npx serve .
```

화면에 나온 주소(예: `http://localhost:3000`)로 접속합니다.

## 알아둘 점

- **기록은 지금 쓰는 브라우저에만 저장됩니다** (`localStorage`, 키 `oneline-diary.entries`). 다른 브라우저나 기기에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 기록도 사라집니다.
- 파일로 열 때와 `npx serve`로 열 때는 주소가 달라서, 서로의 기록이 보이지 않습니다.
- 스타일은 Tailwind CSS CDN에서 불러오므로 **인터넷 연결이 필요합니다.**
