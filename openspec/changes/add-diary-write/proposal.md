# Proposal

## Why

하루를 짧게 남기고 싶은데, 일반 일기장은 쓸 것이 많아 부담스럽다. 오늘 날짜가 자동으로 보이고 한 줄만 적어 저장하면 되는 가벼운 다이어리를 만들어, 브라우저만 열면 바로 기록하고 최근 기록을 훑어볼 수 있게 한다. 이 저장소의 첫 기능으로, 작성과 목록이라는 가장 작은 흐름부터 만든다.

## What Changes

- 화면 상단에 오늘 날짜를 `YYYY-MM-DD` 형식(예: `2026-12-31`)으로 자동 표시한다.
- 한 줄 입력칸과 저장 버튼을 제공한다. Enter 키로도 저장할 수 있다.
- 저장하면 내용과 함께 저장 시각을 기록한다. 같은 날 여러 번 작성할 수 있다.
- 공백만 있는 입력은 저장하지 않는다. 입력은 최대 100자로 제한한다.
- 저장한 기록은 브라우저 `localStorage`에 남아 새로고침하거나 브라우저를 다시 열어도 유지된다.
- 저장한 기록을 최신순 목록으로 보여준다. 목록 영역은 5개 높이이며, 5개를 넘으면 그 안에서 스크롤한다.
- 날짜와 시각은 사용자 기기의 로컬 시간대를 기준으로 한다.

**범위 밖 (이번 change에서 하지 않음)**
- 기록 수정·삭제
- 검색, 태그, 날짜별 필터
- 서버 저장, 기기 간 동기화, 로그인

## Capabilities

### New Capabilities
- `diary-entries`: 한 줄 다이어리 기록의 작성, 저장(localStorage), 목록 표시

### Modified Capabilities
- 없음

## Impact

- 새 파일: 정적 웹 페이지(`index.html`)와 Vanilla JS 스크립트. 빌드 도구 없음.
- 외부 의존성: Tailwind CSS를 CDN `<script>`로 불러온다. 첫 로딩에 인터넷 연결이 필요하다.
- 데이터: 브라우저 `localStorage`에 키 하나로 저장한다. 브라우저 데이터를 지우면 기록도 사라진다.
